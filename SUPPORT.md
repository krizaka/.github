# Getting help

- **Documentation** — [krizaka.com](https://www.krizaka.com): Orazaka and Orochia docs, synced from the code.
- **Questions and ideas** — GitHub Discussions on [`krizaka/orazaka`](https://github.com/krizaka/orazaka/discussions).
- **Bugs and feature requests** — an issue on the repository concerned.
- **Deployments, integrations, partnerships** — the [contact form](https://www.krizaka.com/en/contact).
